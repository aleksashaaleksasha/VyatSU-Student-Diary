# документация API валидации

## POST /api/validate/schedule

валидация данных расписания перед сохранением в БД

### Тело запроса
```json
{
  "group": "string (обязательно, формат: АА-111-11-11)",
  "date": "string (обязательно, ISO формат)",
  "subject": "string (обязательно, мин. 2 символа, макс. 100)",
  "time": "string (опционально, формат: 9:00-10:30)",
  "teacher": "string (опционально, макс. 50 символов)"
}
